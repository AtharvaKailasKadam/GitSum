# GitHub Summarizer

A web application to visualize GitHub user statistics, top repositories, contribution streaks, languages usage, and coding habits in an aesthetic and interactive dashboard.

## Features

- Display GitHub profile information (username, bio, followers, following, company, location)
- Quick statistics: public repos, total stars, forks, and cloud storage used
- GitHub stats cards for overall stats and top languages
- Contribution streak visualization
- Commit activity graph
- Achievements showcase (profile summary)
- Language usage analytics with percentages
- Coding habits visualization
- Top repositories with stars, forks, last updated, and size

## Tech Stack

- React.js
- React Router
- GitHub REST API
- CSS (Custom styling)
- GitHub Stats APIs for dynamic graphs
